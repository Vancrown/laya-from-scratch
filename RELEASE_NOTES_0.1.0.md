# v0.1.0 — Initial educational release

- Bidirectional Transformer and decision-model examples.
- Pretrained BERT decision head, SFT, and temperature scaling.
- RLCD-inspired and continuous Gaussian-logit GRPO-style training.
- Multi-objective reward, evaluation diagnostics, and inference/checkpoint pipeline.

**Scope:** research/educational prototype; not an official Laya reproduction or a validated performance benchmark. Checkpoints are not distributed in this release archive.

**Verification:** static source and notebook structure checked; focused CPU unit checks run. Full BERT notebook execution and reproducibility of model comparisons remain unverified until checkpoints, model downloads, and a full clean-environment run are available.
